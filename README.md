# KINGDOM SERVICES

Site public : https://kingdom-services.netlify.app/

## Identité visuelle

Les trois logos fournis par KINGDOM SERVICES sont conservés tels quels. Home utilise le turquoise et le vert, Créative & Media le violet et le corail, Tech & Sécurité le bleu nuit et le cyan. Les variantes plus sombres assurent la lisibilité du texte et des boutons.

L’image architecturale générée a été retirée. L’accueil présente les trois identités avec une composition HTML/CSS. Toute nouvelle photographie ou image générée doit être validée par le propriétaire avant intégration.

Le catalogue comprend une recherche sans dépendance et fonctionne aussi sans JavaScript. Les 41 prestations et leurs tarifs sont conservés.

Le pôle Tech & Sécurité présente neuf propositions, toutes sur devis : vidéosurveillance, alarme anti-intrusion, contrôle d’accès et interphonie, câblage réseau, Wi-Fi, configuration réseau, dépannage informatique, sauvegarde et protection des postes, maintenance des équipements de sécurité. Le choix d’une prestation prépare la demande d’étude avec son libellé exact.

Site vitrine de KINGDOM SERVICES, Abidjan, Côte d’Ivoire.

## Publication

Le site est statique. Il ne nécessite ni installation de dépendances ni compilation.

- Code à conserver dans le compte GitHub CoolOthniel.
- Hébergement prévu : Netlify, relié au dépôt GitHub.
- Répertoire à publier : `site`.
- Commande de compilation : aucune.
- La configuration est fournie dans `netlify.toml`.
